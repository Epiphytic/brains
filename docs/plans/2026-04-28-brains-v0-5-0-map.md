## Overview

Two independent feature streams ship as v0.5.0. Phase 1 promotes `er` and `sequence` from ADR-002's reserved slots to active types in `brains:diagram` (additive — two new lazy-on-demand reference files, two new rows per routing table, one new heuristic threshold, plus the removal of three "v0.5-only / reserved" gate strings). Phase 2 adds `--grill` as a strategy modifier on `/brains:brains` phase-1 (one new lazy-on-demand reference file plus targeted edits to the brains SKILL.md questionnaire flow). Each phase is independently testable: phase 1 ends with er+sequence diagrams auto-dispatching from synthesis; phase 2 ends with `/brains:brains --grill` running its hybrid-termination questionnaire end-to-end.

[y/N]`), the "1 turn left" exception that skips the prompt to save the round-trip, the auto-batching rule with `batch_size = ceil(remaining / max(1, 8 - turns_used))` clamped to `[2, 5]`, and the requirement that the system MUST emit an upfront message at the start of the grill session communicating the 8-turn budget AND the batching policy.
